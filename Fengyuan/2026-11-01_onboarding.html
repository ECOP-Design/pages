ECOP 上手教程:让 AI 助手在你电脑上干活

写给 Doubao、Mirror、Mingren、Jerry。不需要任何编程基础。全程照着复制粘贴,大约 40 分钟。有卡住的地方直接截图发给 Fengyuan。

先说清楚我们在做什么。

ECOP 团队用一套很简单的方法协作:每个人有一个自己的「工作间」(叫 harness,就是电脑上的一个文件夹),里面住着一个 AI 助手(Claude Code 或 Codex,看你用哪个)。你每天开工让它看一眼大家昨天干了什么,收工让它把你今天干的事记进共享日志。日志和计划放在 GitHub 上,所有人都能看。不开会、不填表,靠这个同步。

要做到这件事,你的电脑需要三样东西:① 能和 GitHub 说话;② 有你的 harness 文件夹;③ 装好 AI 助手。这份教程就是带你把这三样装好。

  2. 知道自己的「名字」。团队里每人一个固定英文名,后面所有命令里的 <名字> 都替换成它,大小写要一样:
    你名字GitHub 账号
    DoubaoDoubaorkayoperation-sys
    MirrorMirrorMirror-Papaya
    MingrenMingrenPsyruto
    JerryJerryJerryHu0808
  3. 一个 AI 助手的账号:用 Claude Code 就要 Claude 账号(Pro 或 Max),用 Codex 就要 ChatGPT 账号(Plus 以上)。两个都有的话,推荐 Claude Code,团队的规则文件是先按它写的。
  4. 一台 Mac。这份教程按 Mac 写。Windows 也能做,但坑多一些,Windows 用户看每一步下面折叠的「Windows 用户」小节,卡住了直接找 Fengyuan 一起装。

1. 认识「终端」5 分钟

终端(Terminal)是一个黑底或白底的窗口,你在里面打一行字、按回车,电脑就执行。所有 AI 助手的命令行版本都在这里面跑。我们要求一律在终端里用 AI 助手,不用网页版、不用 VS Code 插件,原因后面会讲。

怎么打开

按 ⌘+空格,输入 Terminal(或「终端」),回车。看到一个窗口,最后一行有个光标在闪,就是在等你输入。

只需要知道这四件事

  1. 一行就是一条命令。打完按 回车 才会执行。没有回车什么都不会发生。
  2. 复制粘贴。本教程里黑底的框都是命令,整行复制,在终端里 ⌘+V 粘贴,回车。一个框里有好几行就一行一行来。
  3. 「当前文件夹」。终端永远「站在」某个文件夹里,命令都针对这个文件夹。cd 某个路径 就是走到那个文件夹去。~ 是你的个人主目录(就是访达里那个房子图标)。
  4. 没报错就是成功。很多命令成功了什么都不显示,直接回到光标。只有红字或 error、not found、denied 才是出问题。
两个小提醒。
  • 输入密码时屏幕上不会显示任何东西,连星号都没有,正常,打完回车就行。
  • 命令跑着没结束(光标不回来)想中断:按 Ctrl+C。
Windows 用户

开始菜单搜 PowerShell,右键「以管理员身份运行」。下面的命令绝大部分一样,个别不同的地方会单独标。Claude Code 和 Codex 在 Windows 上更建议装在 WSL(Windows 里的 Linux)里跑,这一步比较绕,建议找 Fengyuan 一起装。

2. 装三个基础工具10 分钟

需要三样:git(管文件版本)、gh(让终端能操作 GitHub)、node(AI 助手的运行环境)。Mac 上先装一个「软件管家」Homebrew,然后用它一次装完。

2.1 装 Homebrew

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

中间会要你输入 Mac 开机密码,然后按一次回车确认。要等几分钟。装完它可能提示你再跑两行 echo ... >> ~/.zprofile 开头的命令,照着复制跑一下。

2.2 用 Homebrew 装 git、gh、node

brew install git gh node

2.3 检查

先关掉终端窗口,重新开一个(很重要,新装的东西要重开才认得),然后:

git --version
gh --version
node --version
成功的样子:三行各打出一个版本号,比如 git version 2.x、gh version 2.x、v22.x。哪一行说 command not found,就是那个没装上,回头重跑那一步。
Windows 用户 
winget install --id Git.Git -e
winget install --id GitHub.cli -e
winget install --id OpenJS.NodeJS.LTS -e

装完关掉 PowerShell 重开,同样用上面三条 --version 检查。

3. 把 GitHub 账号和电脑连起来5 分钟

为什么要这一步。团队的日志、计划、你的 harness 都存在 GitHub 上,而且是私有的。你的电脑要能代表「你」去读写它们,就得先登录一次。这一步做完以后就不用再管了。
gh auth login

它会一步步问你问题,用 ↑↓ 选,回车 确认。按下面选:

它问你选
Where do you use GitHub?GitHub.com
What is your preferred protocol for Git operations?HTTPS
Authenticate Git with your GitHub credentials?Yes(输入 Y 回车)
How would you like to authenticate?Login with a web browser

然后它会显示一个 8 位的一次性代码,像 A1B2-C3D4。把这个代码记下来,按回车,浏览器会自动打开 GitHub 页面。在页面里粘贴这个代码,点 Continue,再点绿色的 Authorize。回到终端,看到 Logged in as 你的账号名 就成了。

验证一下:

gh auth status
成功的样子:有一行 ✓ Logged in to github.com account 你的账号名。
浏览器没自动打开?终端里会给一个网址 https://github.com/login/device,手动在浏览器打开,粘代码就行。

4. 下载你的 harness3 分钟

harness 是什么。就是一个文件夹,里面放着:给 AI 看的规则(CLAUDE.md,Codex 用户看的叫 AGENTS.md,内容一样)、三个预先写好的命令(/update、/diary、/publish-html)、团队共享的日志文件夹 diary/ 和计划文件夹 plan/、以及你自己放工作文件的 ecop/。Fengyuan 已经给每个人在 GitHub 上建好了一份,名字替换好了,你只要下载下来。

把下面的 <名字> 换成你的名字(两处都要换,见第 0 节的表):

gh repo clone ECOP-Design/<名字> ~/<名字> -- --recurse-submodules

比如 Jerry 就是:

gh repo clone ECOP-Design/Jerry ~/Jerry -- --recurse-submodules

然后走进去看一眼:

cd ~/<名字>
ls
成功的样子:列出 AGENTS.md CLAUDE.md README.md archive diary ecop plan。再敲 ls diary,能看到五个人的文件夹和 README,说明共享日志也拉下来了。
如果 ls diary 是空的,跑一次 git submodule update --init 再看。
如果报 Repository not found 或 Permission denied:要么第 3 步没登录成功(跑 gh auth status 看),要么你还没被拉进 ECOP-Design 组织(找 Doubao)。

5. 装 AI 助手5 分钟

两个选一个装。一定要装命令行版本,在终端里跑。

为什么必须在终端里、而不是网页或 VS Code 插件。
  • AI 助手启动时,会自动读「当前文件夹」里的 CLAUDE.md / AGENTS.md。你在 harness 文件夹里启动它,它就知道团队的规则、知道 /update /diary 是什么。在别的地方启动它,它什么都不知道。
  • 网页版的 AI 碰不到你电脑上的文件,也碰不到 GitHub,日志和计划它都读不到、写不了。
  • 大家用同一种方式,出问题好互相帮。

选项 A:Claude Code

npm install -g @anthropic-ai/claude-code

装完,进 harness 文件夹启动它:

cd ~/<名字>
claude

第一次启动会让你选主题(随便),然后要登录。选 Claude account with subscription,浏览器打开后登录你的 Claude 账号、点授权,回到终端。

它可能会问「Do you trust the files in this folder?」,选 Yes。这是你自己的 harness,放心。

成功的样子:看到一个输入框,上面有 Claude Code 的字样。随便打一句「你好,你现在在哪个文件夹,CLAUDE.md 里说我叫什么」,它答得出你的名字就说明规则读到了。

选项 B:Codex

npm install -g @openai/codex
cd ~/<名字>
codex

第一次启动选 Sign in with ChatGPT,浏览器登录、授权,回到终端。

成功的样子:看到 Codex 的输入框。打一句「读一下 AGENTS.md 和 CLAUDE.md,告诉我我叫什么、我该怎么开始一天」,它能说出 /update 就对了。

退出

两个都一样:打 /exit 回车,或者按两次 Ctrl+C。

6. 可选:让 AI 不要每步都问你2 分钟

默认情况下,AI 每次要改文件、跑命令,都会停下来问你「可以吗?」,你得按 y。头几次这样挺好,能看清它在干什么。熟了以后会觉得烦,可以开「跳过确认」模式:

平时启动跳过确认模式
Claude Codeclaudeclaude --dangerously-skip-permissions
Codexcodexcodex --dangerously-bypass-approvals-and-sandbox
名字里带 dangerously 不是开玩笑。开了以后 AI 做什么都不问你,包括删文件、往 GitHub 推东西。我们的规则文件里写了「不删除」「不擅自 push」,但那是靠 AI 自觉遵守,不是物理上做不到。所以:
  • 只在 harness 文件夹里开。先 cd ~/<名字> 再启动,别在主目录或桌面开。
  • harness 里的东西都在 GitHub 上有备份,真搞坏了找 Fengyuan 能恢复。但你自己放进 ecop/ 的文件,要记得定期让 AI commit。
  • Codex 的 --dangerously-bypass-approvals-and-sandbox 太长记不住的话,先用 codex --full-auto,它会少问很多但还有基本的保护。

7. 每天怎么用:/update → 干活 → /diary

固定三步,每次打开 AI 助手都这么来:

  1. 开场:/update。它会去 GitHub 拉最新的日志和计划,告诉你队友最近两天干了什么、有没有人给你留了通知(NOTICE)、计划有没有变、你今天该接着干什么。一分钟读完,比开早会快。
  2. 干活。用大白话跟它说你要做什么。你的工作文件放 ecop/ 里。它不会问的时候你不用管它;它问了你就回。
  3. 收尾:/diary。它会把这次会话做的事整理成几条,写进 diary/你的名字/今天日期.md,然后推到 GitHub。队友明天 /update 就能看到。不跑这一步,你今天做的事别人就不知道。

Claude Code 和 Codex 的小区别

Claude CodeCodex
怎么触发 /update直接打 /update 回车打 执行 /update 回车(前面加「执行」两个字,免得它当成自己的内置命令)
怎么触发 /diary直接打 /diary打 执行 /diary
规则文件CLAUDE.mdAGENTS.md(它会让你去读 CLAUDE.md)

说大白话也行,比如「看看大家最近都干了啥」「把今天的事记进日志」,两边都懂。

几条团队规矩,AI 知道,你也最好知道。
  • 只写自己的日志文件夹,别人的只看不改。
  • 不删文件,过时的移到 archive/。
  • 客户的东西不进 GitHub:客户的账号密码、价格表、员工个人信息,一律不放进任何仓库。日志里写「和 X 客户谈了价格」可以,写具体数字不行。
  • AI 不会自己 push(往 GitHub 推东西),除了 /diary 和 /publish-html 这两个预先批准的。你改了 plan/ 里的计划想推上去,要明确跟它说「push」。

8. /publish-html:把网页发给别人看

你让 AI 做了一个网页(原型、报告、图表、Demo),想给队友或客户看,不用发文件、不用截图。跟它说:

/publish-html 那个文件.html

或者直接说「把这个网页发出去给我个链接」。几十秒后它给你一个链接,形如:

https://ecop-design.github.io/pages/<名字>/2026-11-05_xxx.html

任何人点开就能看,手机也行。所有人发过的页面在 ecop-design.github.io/pages/ 能找到。

这些链接是全网公开的。发之前 AI 会先读一遍内容、扫一遍有没有密码密钥,但最终责任在你:含客户数据的东西不要发。发错了也不要以为删掉就没事,GitHub 的历史记录删不干净。

9. 第一次会话做什么10 分钟

装好以后,在 harness 文件夹里启动 AI 助手,按顺序跟它说这几句:

  1. /update(Codex:执行 /update)。它会告诉你 Fengyuan 留了一条给所有人的通知,还会发现 plan/2026-11/assignments.md 里你那一行是空的。
  2. 「把 CLAUDE.md 里『我负责』那行填上:我负责 ______。再把 plan/2026-11/assignments.md 里我那一行也填上,填完 push 到 plan 仓库。」(空格里写你在 ECOP 负责的事,一句话)
  3. 随便让它干点活试试手,比如「把 ecop/research/ 里的 README 看一下,然后帮我建一个今天的会议记录文件」。
  4. /diary(Codex:执行 /diary)。然后去 github.com/ECOP-Design/person 看看你的文件夹里是不是多了一个今天日期的文件。
做完这四步,你就接上了。明天开始就是第 7 节的三步循环。

10. 出问题了怎么办

现象原因和解法
command not found: brew / gh / claude / codex没装上,或者装完没重开终端。先关掉终端重开再试;还不行就重跑那一步的安装命令。
Permission denied、Repository not found、403电脑没登录 GitHub(跑 gh auth status 看),或者你不在 ECOP-Design 组织里(找 Doubao)。
AI 说它不知道 /update 是什么你不在 harness 文件夹里启动的。退出,cd ~/<名字>,再启动。
/diary 推不上去,说 rejected 或 conflict别人刚好也在推。跟 AI 说「先 pull --rebase 再 push」。它会处理。
ls diary 是空的在 harness 文件夹里跑 git submodule update --init。
AI 一直问我「可以吗」正常。按 y。烦了看第 6 节。
AI 说要我输 gh auth login 之类的命令它需要你本人在终端操作。退出 AI(/exit),在终端里跑,跑完再启动 AI。Claude Code 里也可以直接打 !gh auth login,感叹号开头的会当作终端命令。
Homebrew 装了半天不动网络慢,等。超过 20 分钟就 Ctrl+C 重跑。

11. 名词解释

词意思
终端 / 命令行 / CLI打字操作电脑的窗口。CLI = Command Line Interface,命令行界面,一个意思。
Git一个记录文件每次改动的工具,能回到任何历史版本。装在你电脑上。
GitHub一个网站,把 Git 管的文件夹放到云上,多人共享。ECOP-Design 是我们在上面的组织。
ghGitHub 的命令行工具,让终端能直接操作 GitHub。
仓库(repo)GitHub 上的一个项目文件夹。ECOP-Design/person 就是组织 ECOP-Design 下面叫 person 的仓库。
clone把 GitHub 上的仓库下载到自己电脑,只需要做一次。
commit给当前改动拍一张快照并写一句说明。只在本地。
push / pullpush 是把本地的快照推到 GitHub;pull 是把 GitHub 上别人推的拉下来。
submodule一个仓库里嵌着另一个仓库。你 harness 里的 diary/ 和 plan/ 就是嵌进来的两个共享仓库。
harness我们对「AI 助手的工作间」的叫法:一个带规则文件的文件夹。
CLAUDE.md / AGENTS.md放在 harness 根目录、AI 启动时自动读的规则文件。前者 Claude Code 读,后者 Codex 读。
斜杠命令(slash command)/update 这种以斜杠开头的词,对应一份预先写好的步骤说明,AI 看到就照着做。
NOTICE日志仓库根目录里 NOTICE-日期-给谁-主题.md 的文件,是定向通知。/update 会自动读给你听。
GitHub PagesGitHub 的免费网页托管。/publish-html 就是往那里发。
